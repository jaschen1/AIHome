# AIHome 格力空调遥控器 · ESP32-C3 SuperMini

日常使用时，让开发板连接家庭 2.4GHz Wi-Fi，iPhone 连接同一路由器后访问 http://aihome.local/ 或路由器分配的开发板 IP。手机可继续正常上网。设备之间不能启用隔离，远程互联网访问和 Siri 尚未集成验证。

首次设置或家庭 Wi-Fi 断开约 30 秒后，连接备用热点 **AIHome**，密码 `12345678`，在 http://192.168.4.1/wifi 填写家庭 Wi-Fi。配置存入 NVS，断电保留，不写入源码。设置页显示连接状态和家庭 IP。恢复连接 60 秒且备用热点无客户端时关闭热点。串口 `?` 可查看家庭连接与 IP，`s` 可进行诊断扫描（扫描会短暂占用网络，勿在发射期间使用）。

按键提交后，面板先显示待发送设定，再更新为最后发送的设定。客厅和卧室分别保留设定，通过 GPIO4 共用一个红外发射管，发送队列依次执行。空调本身没有状态回传，使用原遥控器或重启开发板后，面板显示可能与空调实际状态有差异。

## 发射电路

先拔下 USB，再用 **S8050 和限流电阻**连接 940 nm 发射管。按手上三极管的实际引脚定义识别 B、C、E。

```text
ESP32 5V  ── 200 Ω ── 红外发射管正极（A）
                      红外发射管负极（K）── S8050 集电极（C）

ESP32 GPIO4 ── 200 Ω ── 200 Ω ── S8050 基极（B）

ESP32 GND ────────────────────── S8050 发射极（E）
```

用带驱动的红外模块时，GPIO4 接它的 3.3 V 逻辑、有效高信号输入，模块与 ESP32 共地，供电按模块标注。本固件使用 GPIO4 上的 ESP32-C3 RMT 发射 38 kHz 调制红外。首次接好后把发射管对准空调接收窗，近距离先试 **制冷**，再试 **开／关**。空调响铃或显示变化可用于确认接收。GPIO5 接收模块可拔下。5 V 供电仅用于发射管支路。插拔面包板上的杜邦线前先拔掉 USB。

## 按键行为

- 按键生成包含整套设定的红外帧。制冷和制热快捷键会发开机状态，温度从当前设定延续。
- 温度范围为 16–30 °C。自动、除湿和节能状态下调温会提示受限。节能开启时固定自动风。普通模式的风速使用 Kelvinator 的自动档和 1–5 档编码。
- 定时使用录到的 **30 分钟**格式，再按一次发送清除定时位的普通帧。定时取消是否立即生效需要在空调上验证。
- 制热下「干燥／辅热」切换原遥控器实测到的数据位。制冷或除湿下用协议的干燥位。各模式和附加功能是否执行取决于具体室内机。
- 适用范围是本次抓码的这只格力遥控器。另一只型号或协议不同的遥控器对应空调需要另做验证。

## 编译与验证

VS Code 中打开本目录，在 PlatformIO 的 **General** 下选 **Build** 或 **Upload**。串口 115200，输入 `?` 查看热点、连接设备数、开机时间、复位原因和发射初始化状态，输入 `t` 测试输出一帧关机码。

- 客厅页面为 `/`，卧室页面为 `/bedroom`，右上角可互相切换。
- `GET /api/ac` 返回客厅设定与 `pending` 数量，卧室对应 `/api/bedroom/ac`。待发数量归零表示开发板已完成发射。
- `POST /api/ac` 使用 `Content-Type: application/json`，例如 `{"key":"cool"}`。
- 编码器复现了 16 份抓码样本的完整载荷。普通帧含两个数据段，实测 30 分钟定时帧含三个数据段。样本保存在 `docs/remote-ir-pulses.json`，按键对照见 `docs/remote-ir-key-map.md`。

[RMT 调制输出参考](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/rmt.html) · [Kelvinator 波形和校验参考](https://github.com/crankyoldgit/IRremoteESP8266/blob/v2.9.0/src/ir_Kelvinator.cpp)

## 局域网响应优化

USB 供电下关闭 Wi-Fi modem sleep，优先保证按键响应，功耗会相应增加。手机提交指令时取消未完成的后台状态查询，减少并发请求。超时的控制指令不会自动重发。红外帧仍按原始时序发送，普通帧约 0.3 秒，定时帧约 0.5 秒。

## 动态手机面板

界面提供温度环、冷暖配色、送风与扫风动画，保留全部 16 个控制功能。动画展示发送设定，不代表室内机反馈；离线、尚未发送及发送失败时不展示运行送风动画。支持系统减少动态效果设置，所有样式和脚本内置，无需互联网资源。
